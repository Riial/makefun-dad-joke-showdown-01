## The joke

> Why did the Queen go to the dentist? She needed a new crown.

A crown is both the headpiece a monarch wears and the cap a dentist fits
on a tooth. Clean wordplay, lands on first read, punchline at the end.

## How it works

`main.py` writes the joke to `/output/entry.txt` (UTF-8, 60 characters,
within the 1–200 character gate). It is fully deterministic: every run
produces byte-identical output, and it asserts the gate conditions
(length, non-blank, valid UTF-8) before writing.
